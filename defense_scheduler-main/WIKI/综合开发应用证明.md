## 一、应用功能概述

本应用（现名"答辩安排助手"）面向研究生答辩安排场景，将原本依赖人工 Excel 交叉核对的分组排期工作系统化、自动化：

1. **五步向导与工作台**：工作台根据真实资料和当前排期提示下一步；"开始一次答辩安排"进入五步向导（选择类型 → 准备资料 → 确认要求 → 生成与核对 → 发布与导出），缺资料阻止继续、返回保留输入、刷新按 URL 恢复步骤。
2. **基础数据管理**：教师（学院、职称、可担任角色、可参与答辩类型、校区偏好、不可用时间、回避教师）、学生（类型、导师、校区、答辩类型、指定秘书）、教室（校区、容量、可用时间）的增删改查与 Excel 批量导入。
3. **课表导入**：支持卡片式课表文件解析，自动生成教师不可用时间，导入前提供预览与未识别条目告警。
4. **规则配置中心**：按预答辩 / 正式答辩 / 中期答辩三种类型独立配置人数规则（学生目标/上下限、专家数、秘书数）、角色资格规则（组长/秘书最低职称、高职称优先）、时间规则（日期区间、避开周末节假日、指定排除日期）、导师回避开关，以及 5 项软约束权重（组间人数均衡、高职称优先、避免跨校区、校外导师集中度、学硕优先）。
5. **自动排期**：内置求解算法（`algorithm.py`），依据硬约束 + 软约束权重自动完成学生分组与时间、教室、主席、秘书、专家分配；支持多版本管理与"草稿校验 → 发布"流程。
6. **日程视图与人工调整**：日程视图按日期和时段展示分组，配合卡片/表格视图与日期/校区/问题筛选；支持学生换组、更换专家/主席/秘书、调整时间/教室；每次调整自动触发冲突检测（数据完整性、导师回避、专家重复、时间/容量冲突等），以冲突面板逐条展示原因与建议。
7. **导出**：Excel 排期表（每组一个工作表，导师-学生同名同色富文本着色）与 Word 排期表（python-docx 正式排版）。
8. **安全与审计**：Django 认证（登录/登出/改密）、服务端操作日志审计、并发写锁与生成请求去重、数据库迁移前自动备份。

## 三、可复现性说明

1. 克隆项目后执行 `pip install -r requirements.txt`；
2. 执行 `python main.py`，首次启动自动完成数据库迁移并生成管理员账号（`app-data/INITIAL_ADMIN.txt`）；
3. 登录后依次导入项目根目录提供的 `批量测试_教师_30人.xlsx`、`批量测试_学生_100人.xlsx`、`批量测试_教室_10间.xlsx`；
4. 在"排期结果"页点击"一键生成排期"即可复现自动排期与冲突检测结果。

详细功能说明、输入/输出格式与接口文档见 [WIKI.md](../WIKI.md)。

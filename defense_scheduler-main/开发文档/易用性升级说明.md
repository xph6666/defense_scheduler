# 易用性升级记录（2026-09-18）

## 解决的问题

老师反馈“不知道先做什么、下一步去哪”。本次调整围绕首次操作路径：

**工作台 → 准备资料 → 确认要求 → 生成与检查 → 发布与导出**。

首页根据真实资料和当前排期提示下一步；资料加载失败时明确显示失败，不把失败显示成“没有资料”。答辩类型在页面间保留，也支持通过链接中的 `type` 参数进入指定类型。

## 原有功能的入口

| 功能 | 新界面入口 |
| --- | --- |
| 学生、教师、教室的搜索、新增、编辑、导入、批量删除 | 工作台资料卡片或左侧资料管理 |
| 教师课表导入 | 教师与专家页面 |
| 日期、每组目标人数 | 安排要求页面，直接展示 |
| 人数上下限、启用类型、导师回避、角色资格、分组权重 | 安排要求 → 更多要求 |
| 恢复默认、仅保存 | 安排要求底部 |
| 生成排期 | 答辩安排与导出 → 生成排期草稿；先确认摘要 |
| 卡片视图、表格视图 | 答辩安排页面顶部 |
| 手动调整人员、时间、教室 | 具体分组 → 调整 |
| 学生换组 | 当前草稿 → 移动学生 |
| 刷新、重新检测冲突 | 更多操作；检测面板也保留重新检测 |
| 分组质量评分 | 结果侧栏 → 查看分组质量评分 |
| 历史版本、发布、Word/Excel 导出 | 答辩安排与导出 |
| 全类型统计、开发环境演示重置 | 工作台底部可展开区域 |
| 操作日志、密码修改、退出登录 | 左侧其他工具及右上角 |

日期控件等 Element Plus 文案统一使用中文。新增右上角“使用帮助”和《教师快速上手》说明。

## 验证记录

- `npm run build`：通过，包含 TypeScript 检查；构建仍有 Element Plus 大分块体积提示。
- `npm run lint`：通过，无错误或警告。
- 原有 dashboard overview、optimization 检查：通过。
- 隔离 SQLite 数据库 + Waitress + Chromium：走通跨页面保留类型、展开并保存高级设置、生成前确认、生成草稿、发布、Word 和 Excel 下载。
- 补充回归：草稿调整保存、学生移动对话框、重新检测菜单、历史已发布版本查看及只读限制。
- 空资料、接口失败、规则读取失败、只读用户、390px 窄屏首页：通过；浏览器未捕获到未处理脚本错误。
- 对比原规则表单：22 项配置绑定全部保留。
- 新版 EXE 在独立空目录中启动，完成初始化、健康检查、登录及工作台首步导航检查；压缩包完整性校验通过，仅包含程序和教师说明。

测试使用独立临时数据，不修改工作目录中的业务数据库。以上验证覆盖交互和功能可达性；老师实际使用是否更容易上手，仍需通过真实试用反馈确认。

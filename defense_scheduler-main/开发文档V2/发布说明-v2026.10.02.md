# 答辩安排助手 · V2 架构升级版（v2026.10.02）

Windows 64 位单文件版。下载 `DefenseScheduler-v2026.10.02-win-x64.zip`，解压后双击 `DefenseScheduler.exe` 即可运行，无需安装 Python 或 Node.js。

## 本次升级

- 前后端共用 V2 场景政策，统一专家人数、角色资格、软件学院专家底线和课程半天回避。
- 教师增加启用、组员资格及软件学院标记；学生使用稳定的导师与秘书 ID 关系。
- 新增预答辩与正式答辩联合生成，固定继承本轮分组和秘书；导师与自己的学生同一时段到场，在不同评审组参加正式答辩。
- 加强版本隔离、手动调整、秘书保留与显式改绑，保护历史排期快照。
- Excel 支持教室学生明细、备注和错误标记；新增所选历史版本 PDF 打印与保存入口。
- 中期答辩支持分校区开始日期，优化软件学院评审轮换和外院到场日集中。

## 首次使用与旧版升级

首次启动会自动创建管理员，账号和随机密码保存在程序目录的 `app-data/INITIAL_ADMIN.txt`。默认访问 `http://127.0.0.1:8000`，端口占用时自动选择空闲端口。

升级旧版时，请先关闭程序，备份原程序目录的整个 `app-data` 文件夹，再替换 `DefenseScheduler.exe`。保留原 `app-data` 后启动，新程序会自动备份并迁移数据库。`secret.key`、数据库和原管理员账号需要一起保留。

发布压缩包仅包含程序、使用说明和校验文件。实际业务数据库、管理员凭据及本机密钥不包含在下载包中。使用 `SHA256SUMS.txt` 核对下载附件。

## 实现范围

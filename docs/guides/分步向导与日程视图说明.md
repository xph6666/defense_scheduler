# 分步向导与日程视图（2026-09-19）

## 操作变化

- 工作台新增“开始一次答辩安排”，左侧保留完整管理入口。
- 五步流程：选择类型 → 准备资料 → 确认要求 → 生成与核对 → 发布与导出。
- 缺资料时阻止继续，提供导入和管理入口；从管理页可直接返回资料准备步骤。
- 常用规则直接展示，原有高级规则仍可展开。保存失败留在原步骤并保留输入；隐藏参数造成的人数范围问题给出明确提示。
- 返回上一步保留尚未保存的要求；离开向导或切换类型前提示未保存内容。刷新后按 URL 恢复步骤，重新读取服务器已保存数据。
- 第四步展示分组核对，第五步提供发布；草稿导出、历史版本、移动学生等原有功能保留。
- 新增日程视图，按日期和时段展示分组。可展开名单、调整本组、查看问题；日期/校区/问题筛选也适用于卡片和表格视图。全局冲突仍在冲突面板展示。
- 切换步骤时滚动到顶部并聚焦步骤标题，支持窄屏布局。

## 验证

使用临时 SQLite 数据库、真实后端及 Chromium 浏览器验证以下流程，不使用业务数据库：

1. 全部五步、类型保留、进入管理页后返回向导、导入入口。
2. 隐藏人数范围校验、返回上一步保留输入、离开前取消确认、保存失败后重试。
3. 生成确认、日程/卡片/表格切换、校区和问题筛选、调整保存。
4. 发布、Word 与 Excel 下载、刷新第五步恢复状态。
5. 空资料、接口错误、只读账号、异常步骤参数与 390px 窄屏。

构建：`npm run build`；静态检查：`npm run lint`。

浏览器回归脚本：先在独立终端运行 `.venv\Scripts\python scripts\ui-fixture-server.py`，再运行 `.venv\Scripts\python scripts\test-wizard-ui.py`。测试服务只监听 `127.0.0.1:8769`，测试账号仅在临时数据库中创建；使用完毕关闭测试服务。

发布文件放在 `release/wizard-20260919`。旧用户更新程序时先备份，并保留原 `app-data` 目录。

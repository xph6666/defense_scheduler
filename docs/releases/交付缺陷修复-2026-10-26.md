# 五项交付审查缺陷修复

本轮基于主线 `098ef77`，在本地分支 `codex/fix-delivery-defects` 修复 PRD-003、PRD-021、PRD-035、PRD-040 相关问题。改动涉及普通导入、正式同场匹配、共享配色和评分；无模型迁移或依赖变更。当前为未提交的本地修复工作区，不代表已经合入远程或完成最终交付。

## 问题与结果

| 问题 | 修复后的行为 | 主要回归 |
| --- | --- | --- |
| 普通学生导入未识别带校区选项的地点表头，兴庆被保存为创新港 | 识别预／正式／中期地点表头及中英文括号、空格和选项顺序；预览与确认均保留兴庆 | `api/test_delivery_regressions.py` 的预览无写入、确认保存与表头变体 |
| JSON 参与环节被按逗号拆坏 | 先解析 JSON 数组，再校验合法环节并去重；继续支持分隔文本和已有合法环节合并；坏 JSON、未知枚举或非数组整批拒绝，直接学生 API 同样校验 | 同文件的数组、原有环节保留、坏行原子拒绝及直接 API 用例 |
| 关闭导师回避的正式单组随机遗漏导师 | 同场匹配允许合法的单组场次，先覆盖必需导师，再填普通席位；开启回避时仍保留冲突与发布门禁 | 相同输入的种子 `20261023`、`101`、`1`、`2` 均有导师且可发布；不可行回避例仍拒绝发布 |
| 哈希槽位碰撞导致不同导师同色 | 按所选版本的完整导师集合统一分配，碰撞避让并支持超过 64 位；筛选不重分配；网页师生标签、PDF、Excel 和 Word 使用同一规则 | 冻结历史导出、碰撞姓名、超过色板容量、输入顺序及跨端一致性 |
| 外院集中评分跨校区误扣分 | 按“导师、校区”组合核算，与硬规则一致；缺身份或校区时不猜测得分 | 两校区都合规为 100/100，一校区不合规为 50/100，缺校区为未评估 |

配色分配规则和兼容影响见 [ADR 0002](../architecture/adr/0002-按排期分配导师颜色.md)。已冻结版本使用其自身保存的导师集合，不从当前教师名册或界面筛选重建集合。修复会纠正历史导出中原有的重色；不会改写冻结的人员关系或排期数据。

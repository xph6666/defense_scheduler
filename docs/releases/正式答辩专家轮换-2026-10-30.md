# 正式答辩专家轮换（2026-10-30）

适用于新生成的 policy 3 正式答辩，改动保留在工作区，尚未提交或发布。

## 行为变化

- 沿用预答辩组号、学生与秘书；本组原组长和专家全部更换。导师不能担任本组评审或秘书，且不要求到场。
- 固定 5 位评审含主席，外院至多 1 位。主席优先教授／研究员，不足时按预答辩组长职称放宽并提示。
- 联合与单独正式生成使用统一派生规则；前端将旧正式人数配置迁移为 5 人，轮换时固定开启导师回避。
- 优先集中较早日期、减少同日跨校区、平衡评审次数；同日跨校区是软目标，不保证绝对消除，发生时返回提示。
- 日期不足时保留可安排的组，并逐人说明容量不足、秘书不可用或无合格评审组合；预检新增半天数及人员容量提示、未填写节假日提醒。
- 预答辩按时段独立计算补专家搜索预算，短日期按人员容量限制目标组数，区分时间、占用及容量原因。
- 5 专家快照试跑发现外院组长可能绕过“第二位外院须为本组导师”的限制。候选生成、并行资源预检和保存结果校验已统一限制；新增最小回归样例，确认修复前失败、修复后通过。

显式关闭沿用分组的兼容调用仍独立分组；历史 policy 1/2 和已保存版本不追溯改写。

## 验证与复现

新增 `api/test_formal_rotation.py`，覆盖导师和原评审无需到场、主席职称放宽、半天容量不足、沿用秘书不可用。更新联合生成及独立正式生成测试，检查学生和秘书保留、原评审全部轮换、导师回避、人数及幂等重试。

质检脚本 `scripts/qa/balanced-pre-snapshot.py` 以 SQLite 只读方式读取当前版本输入快照，在内存生成，不保存新排期。检查评审人数、导师回避、原评审更换、学生秘书保留、时间及人员互斥，并记录主席职称放宽与同日跨校区次数。

```powershell
.venv/Scripts/python.exe manage.py test --noinput
npm run test:domain
npm run build
npm run lint
.venv/Scripts/python.exe scripts/qa/balanced-pre-snapshot.py --database app-data/db.sqlite3 --expert-count 3 --output .tmp/rotation-real-3-repeat.json
.venv/Scripts/python.exe scripts/qa/balanced-pre-snapshot.py --database app-data/db.sqlite3 --expert-count 5 --output .tmp/rotation-real-5.json
```

回归同时发现本机免登录认证作为首个认证器缺少挑战头，导致不符合本机条件的令牌请求失败时返回 403。补充 `Token` 挑战头，保留既有 401 契约，不改变本机免登录的来源限制。

数据试跑使用当前版本保存的输入快照，不代表重新读取现有全部教师资料，也不替代页面人工验收。两个输入快照中各有 86 位教师仍按未确认时间的兼容假设参与草稿生成，时间假设核对仍是发布前的人工作业。

前端检查中 `npm run lint` 会递归扫描工作区；后端测试在工作区创建的 `tmp*/`、`pre-plan-*/` 临时目录可能在 Windows 下触发 `EPERM`。本轮使用 `npm run lint -- --ignore-pattern 'tmp*/' --ignore-pattern 'pre-plan-*/'` 排除运行产物，仍检查全部 TypeScript 和 Vue 源码。构建有依赖浏览器数据较旧、部分资源包超过 500 kB 的提示，未在本轮改动依赖或打包策略。

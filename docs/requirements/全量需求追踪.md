## 验收证据维护

实施 PR 关联 `PRD-xxx`，验收后为条目补充提交／PR、输入场景、预期结果、实际结果和日期，再改为“已验收”。一项包含多个条件时，全部条件满足才能通过。暂缓项恢复时记录新的范围和目标日期。

最终交付还需回归、迁移副本、实际 EXE、使用升级说明与校验摘要。异步队列、PostgreSQL 容量和架构拆分属于此前工程增强建议，纳入本期业务范围需要另有需求依据，不能用它们替换或遗漏本表需求。
